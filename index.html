Introduction

What is NextRound?

A full mock interview, from setup to scorecard. Pick a company, role and difficulty, then work through coding, technical and HR rounds with an interviewer that reacts to what you say.

Most platforms only check whether your code passes. NextRound also asks the questions an interviewer would: why this approach, what is the complexity, what breaks at 100x the input.

It is built for Hacktoberfest and open to contributions: swap in a model, add a language, write a question pack.

Read the contributing guide

What you get

Four rounds. One honest report.

DSA coding rounds

Monaco editor with Python, C++ and Java. Run 5 open cases or submit against 10, 5 of them hidden. Real execution, no faked passes.

Technical round

A spoken discussion on architecture, system design and your resume projects, with follow-ups that depend on your answers.

HR round

Behavioral questions framed around STAR, with a different scenario whenever you say you have no example.

Voice and typing

Speak with push-to-talk and interrupt the interviewer, or type. Speech is transcribed through your own provider.

Proctored mode

Fullscreen guard and a 3-strike focus monitor, plus a camera self-view that is never stored or uploaded.

Evidence-based scorecard

Coding scores come from test results. Only rounds you finished are scored. You get strengths, gaps and next steps.

How it works

Download, add a key, start talking.

  1. 01

    Download the app

    Grab the latest build from GitHub Releases and open it.

  2. 02

    Add your API key

    Paste a Gemini, OpenAI, Groq or Anthropic key. It is saved in a local database on your device.

  3. 03

    Set up and interview

    Choose company, role, difficulty and rounds. Optionally add your resume, then begin.

Common questions

Everything else, answered.

Does it cost anything?

NextRound is free and MIT licensed. You pay only for the API usage on your own provider key.

Where does my data go?

Keys, resumes and past interviews live in a local SQLite database. Prompts and answers go to the AI provider you choose. Camera video is never stored or uploaded.

Which languages can I code in?

Python, C++ and Java. C++ and Java need g++ or javac available on your PATH.

How do I contribute?

Fork the repo, create a feature branch, test locally and open a pull request. Ideas range from UI polish to new providers, languages and question packs.
